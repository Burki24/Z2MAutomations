# Z2MAutomations

Dieses Modul ist der Einstieg für die geplante Verwaltung von
Zigbee2MQTT-Automationen in Symcon.

## Voraussetzungen und Einrichtung

IP-Symcon ab 9.0 mit PHP 8.5. Aktuell ist das Modul ein Grundgerüst:
Nach dem Anlegen bleibt es inaktiv (Status 104). Das Konfigurationsformular
weist darauf hin, dass Übertragung und Ausführung noch nicht verfügbar sind.

Es gibt noch keine Einstellungen, Variablen oder öffentlichen Modulfunktionen.
Es werden keine Netzwerkverbindungen hergestellt oder Geräte geschaltet.
